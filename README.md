# Text Space Replacer

🔹 Description:
This is a simple Python program that takes a text input from the user and replaces all spaces with ellipses (...).

🔹 Features:
- Accepts user input
- Replaces spaces with "..."
- Demonstrates basic string manipulation

🔹 Technologies:
- Python

🔹 Purpose:
Created to practice string methods and text transformation in Python.
